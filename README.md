# Kunal Pawar Portfolio

A modern portfolio application built with Next.js, React and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Customize

- Update content in `app/page.tsx`
- Update design in `app/globals.css`
- Add project images in `public/`
- Add your actual resume PDF to `public/` and link it from the navigation or contact section

## Portfolio sections

- Hero
- About
- Experience
- Selected Projects
- Technology Stack
- Patents
- Contact
